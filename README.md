# Финальный проект 7-го спринта: API Яндекс Самокат

Автотесты API учебного сервиса `https://qa-scooter.education-services.ru/`.
Покрыты создание и авторизация курьера, создание заказа и список заказов,
а также удаление курьера, принятие заказа и получение заказа по номеру.

## Установка и запуск

Установи зависимости:

```bash
pip install -r requirements.txt
```

Запусти все тесты с сохранением результатов Allure:

```bash
pytest --alluredir=allure-results
```

Для просмотра отчёта установи Allure Commandline и выполни:

```bash
allure serve allure-results
```

Тесты обращаются к учебному API и создают тестовые заказы. Созданные в тестах
курьеры удаляются после проверки.
